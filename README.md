# 🏫 School Management System

A web-based **School Management System** developed using **Python and Django** to digitally manage student records, teacher information, attendance, examinations, and academic activities.

The system provides separate functionalities for **Admin, Teachers, and Students**, ensuring efficient school administration, organized data management, and a seamless academic experience.

---

## 📌 Project Overview

The School Management System is designed to automate and simplify daily school operations through a centralized web-based platform.

The **Admin** can manage students, teachers, classes, subjects, and academic records. **Teachers** can maintain attendance, manage examinations, and update student results, while **Students** can access their academic information, attendance records, and examination results.

The project provides a user-friendly and responsive interface using **HTML, CSS, and Bootstrap**, with **Python Django** as the backend framework.

---

## 🎯 Project Objectives

- Digitize and automate school administration.
- Efficiently manage student and teacher records.
- Maintain class and subject information.
- Track student attendance.
- Manage examinations and academic results.
- Provide role-based access for Admin, Teachers, and Students.
- Reduce manual paperwork and administrative workload.
- Improve data accuracy and operational efficiency.
